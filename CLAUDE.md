# TrueAchievements Extra

At the start of every session in this repo, load the project skill `trueachievements-extra` (`.claude/skills/trueachievements-extra/SKILL.md`) and follow it. It covers setup, commands, where code goes, specs, live checks and the repo's rules.

It begins with reading the skill's `local.md` (git-ignored: this developer's account and machine). If that file doesn't exist, offer to create it before starting the task, as the skill's `creating-local.md` describes.
